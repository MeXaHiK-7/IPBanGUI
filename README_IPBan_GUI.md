Повнофункціональний графічний інтерфейс та центр керування системою захисту [DigitalRuby IPBan](https://github.com/DigitalRuby/IPBan) для Windows (Windows 10, Windows 11, Windows Server 2012 R2 / 2016 / 2019 / 2022 / 2025).

Розроблено для системних адміністраторів, фахівців з кібербезпеки, DevOps та користувачів виділених серверів.

## Завантаження та релізи

Готові скомпільовані автономні `.exe` файли доступні на сторінці [**GitHub Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest):
* **`Setup_IPBanGUI.exe`** — Графічний майстер встановлення (автоналаштування ярликів, автозапуску та аудиту безпеки).
* **`IPBanControlCenter.exe`** — Портативний автономний запуск (без необхідності встановлення).
* **`IPBanGUI-v2.2.5.zip`** — Повний релізний архів із програмою та документацією.

## Встановлення та запуск

### Варіант 1: Майстер автономної інсталяції (Рекомендовано)
1. Завантажте та запустіть **`Setup_IPBanGUI.exe`** з розділу [**Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest).
   - Файл `Setup_IPBanGUI.exe` є **повністю автономним (Single-File)**: всі скрипти, бібліотеки та іконки вбудовані всередину файлу.
   - Не вимагає наявності Git чи сторонніх компонентів.
2. Пройдіть кроки майстра:
   - Вибір шляху встановлення (за замовчуванням `C:\Program Files\IPBan Manager`).
   - Створення ярликів на Робочому столі та в меню «Пуск».
   - Додавання в автозапуск Windows (згорнуто у трей).
   - Автоматична активація аудиту безпеки Windows (`AuditPol`).
   - Перевірка та запуск служби IPBan.
3. Програма реєструється у системному списку «Встановлені програми» Windows із коректним деінсталятором, що зберігає ваші налаштування при оновленні або перевстановленні.

### Варіант 2: Автономний швидкий запуск (Без інсталяції)
- Завантажте та запустіть **`IPBanControlCenter.exe`** з розділу [**Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest).
- Автоматично запитує права адміністратора (UAC) при старті та працює як портативний застосунок.

## Основні можливості

### 1. 📊 Оперативна аналітика та статистика атак (Вкладка «Статистика»)
- **4 оперативні KPI картки**:
  - Всього заблоковано локальних IP-адрес.
  - Кількість унікальних країн-джерел атак.
  - Головна країна атак з відсотковою часткою.
  - Піковий часовий проміжок найбільшої активності атак.
- **Рейтинг країн за кількістю атак (Ліва панель)**:
  - Таблиця топ-країн з прапорами, кількістю заблокованих IP, відсотком від загального обсягу та візуальними псевдографічними гістограмами (`████░░░░`).
- **Розподіл атак за 24 годинами доби (Права панель)**:
  - Погодинний графік активності (00:00 – 23:00), побудований на основі точного часу локальних блокувань IPBan та журналу невдалих входів Windows Security (Event ID 4625).
  - Автоматичне виділення пікової години червоним кольором та інформаційним банером попередження.
  - Окрема ізольована статистика: розрахунок ведеться виключно за реальними локальними атаками на ваш сервер, без спотворення хмарними базами.

### 2. 🛡️ Інтеграція з хмарною базою загроз AbuseIPDB
- **Завантаження актуальних чорних списків**: Отримання до 10 000 підтверджених шкідливих IP-адрес безпосередньо через офіційний API AbuseIPDB з налаштуванням порогу впевненості (90–100%).
- **Ізольована архітектура**: Завантажені хмарні адреси зберігаються в окремому списку `🏴 Чорний список (Blacklist)` і не засмічують екран локальних банів.
- **Опція авто-репорту**: Можливість автоматично повідомляти про виявлені атаки на ваш сервер у глобальну базу AbuseIPDB (за замовчуванням вимкнено для приватності).

### 3. 🔍 Моніторинг 12 протоколів та сервісів Windows
- Зручний контроль та індикація захисту служб:
  - **Дистанційний доступ**: RDP (3389), OpenSSH (22), MS VPN RRAS (1723/4500), RD Web Access (443), VNC (5900).
  - **Бази даних**: MS-SQL Server (1433), MySQL / MariaDB (3306).
  - **Веб та передача файлів**: HTTP / Web (80/443), FTP (21).
  - **Поштові служби**: SMTP (25/587), IMAP (143/993), POP3 (110/995).
- Наочні статусні бейджі (🟢 **Включено** / ⚪ **Вимкнено**) з автоматичною генерацією XML-правил блокування у конфігурації `ipban.config`.

### 4. 💾 Довічне збереження налаштувань (Persistent Settings)
- Загальносистемне надійне сховище конфігурації у `C:\ProgramData\IPBanControlCenter\settings.json`.
- **Зберігається при перевстановленні чи оновленні**: API-ключі AbuseIPDB, обрані галочки сервісів, мова та поведінка трею автоматично підтягуються при повторному встановленні.
- Автозбереження «на льоту»: будь-яка зміна на формі миттєво записується у сховище та реєстр.

### 5. 🔔 Керування службою Windows та системний трей (System Tray)
- **Індикація стану служби кольоровим щитом**:
  - 🟢 **Працює (Running)**: зелений щит-іконка. Сервер під надійним захистом.
  - 🔴 **Зупинено (Stopped)**: червоний щит (якщо служба зупинена або не встановлена).
  - 🟠 **Тривога (Alert)**: помаранчевий щит зі знаком оклику + спливаюче сповіщення Windows BalloonTip при новому блокуванні атакуючих IP.
- **Контекстне меню у треї**: швидкий перегляд лічильника банів, керування службою (старт, стоп, рестарт), відкриття вікна або вихід.
- **Фонова робота**: при натисканні на хрестик `[X]` вікно згортається в трей, забезпечуючи цілодобовий захист.

### 6. 🌍 Визначення країн зловмисників (GeoIP) та прапори
- **Асинхронний GeoIP резолвер**: визначає країну походження атакуючого IP без затримок та підвисань інтерфейсу.
- **Локальний дисковий кеш (`geoip_cache.json`)**: мінімізує мережеві запити, швидко підвантажуючи вже відомі країни.
- **Emoji-прапори та коди**: відображення прапора та назви країни (наприклад, `🇺🇸 US - United States`, `🇩🇪 DE - Germany`, `🇺🇦 UA - Ukraine`).
- **Автовизначення локальної мережі**: приватні та внутрішні діапазони (`192.168.*`, `10.*`, `172.16-31.*`, loopback) маркуються як `🏠 LAN - Local Network`.

### 7. 🚫 Вкладка «Заблоковані IP» (Firewall Rules)
- **Відокремлення локальних блокувань від хмари**: швидке перемикання між режимами:
  - `⛔ Тільки локальні блокування` (нападники, що атакували сервер)
  - `⚪ Тільки білий список` (довірені IP)
  - `🏴 Чорний список (Blacklist)` (хмарна база AbuseIPDB)
  - `📋 Всі правила IPBan`
- **Точний час подій**: відображення дати і часу блокування, а також зворотного відліку до автоматичного розблокування.
- **Whois в один клік**: прямий перехід на ipinfo.io для детального аналізу хоста.
- **Керування блокуваннями**: розблокування виділених IP (через `unban.txt`), ручне блокування підозрілих підмереж, безпечне очищення виключно локальних банів.
- **Експорт**: вивантаження повного списку в `.txt` або `.csv`.

### 8. ⚙️ Вкладка «Налаштування» (Config Editor)
- Візуальне редагування параметрів файлу `ipban.config`:
  - Кількість спроб входу до блокування (`FailedLoginAttemptsBeforeBan`).
  - Тривалість блокування (`BanTime`) зі зручними пресетами (1 день, 3 дні, 1 тиждень, 30 днів, назавжди).
  - Інтервал циклу опитування (`CycleTime`) та скидання спроб (`ExpireTime`).
- Автоматичне створення резервної копії `ipban.config.bak` перед збереженням із можливістю відновлення в один клік.

### 9. 📋 Вкладка «Білий / Чорний списки» (Whitelist & Blacklist)
- Керування довіреними та постійно забороненими підмережами.
- **Захист від випадкового самоблокування**: спеціальні кнопки для автоматичного визначення та додавання локального IP мережевого адаптера (`+ Додати локальний IP`) та зовнішньої статичної адреси (`+ Додати публічний WAN IP`).

### 10. 📑 Вкладка «Журнал та аудит» (Event Log & Audit)
- **Аудит спроб входу Windows (Event ID 4625)**: перегляд атак на RDP, SMB та інтерактивний вхід у реальному часі із зазначенням облікового запису, типу входу та IP-адреси нападника. Можливість заблокувати атакуючого безпосередньо з рядка журналу.
- **Журнал IPBan (`logfile.txt`)**: вбудований переглядач із можливістю автооновлення кожні 5 секунд та швидкого очищення.

### 11. 🔄 Автоматична перевірка оновлень
- Фонова перевірка релізів на GitHub: програма своєчасно сповістить про вихід нової версії з можливістю завантаження в один клік.

### 12. 🌐 Двомовний інтерфейс (Українська / English)
- Повна підтримка української та англійської мов із автоматичним визначенням локалі Windows.
- Перемикання в один клік кнопкою **`🌐 UA`** / **`🌐 EN`** у верхній панелі.

## Збирання з вихідного коду

Для компіляції автономних `.exe` файлів за допомогою штатного компілятора .NET Framework:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build_Binaries.ps1
```

Результатом складання є:
1. `app.ico` — багатошарова векторно-растрова іконка щита.
2. `IPBanControlCenter.exe` — автономний запускний файл.
3. `Setup_IPBanGUI.exe` — графічний майстер встановлення.
4. `release/IPBanGUI-v2.2.5.zip` — готовий ZIP-пакет релізу.
