# IPBan Manager & Control Center (GUI)

Повнофункціональний графічний інтерфейс для керування системою захисту DigitalRuby IPBan на Windows (Windows 10, Windows 11, Windows Server 2016 / 2019 / 2022 / 2025).

---

## Встановлення та запуск

### Варіант 1: Повноцінний автономний інсталятор (Рекомендовано)
1. Запустіть **Setup_IPBanGUI.exe** (або Setup_IPBan_Control_Center.bat).
   - Файл Setup_IPBanGUI.exe є **повністю автономним (Single-File)**: усі компоненти, скрипти та іконки вже вбудовані всередину виконуваного файлу.
   - Його можна запускати на будь-якому комп'ютері чи сервері окремо — жодних супутніх файлів не потрібно.
2. Відкриється графічний майстер встановлення (Wizard):
   - Вибір папки для встановлення (за замовчуванням C:\Program Files\IPBan Manager, працює на будь-якому диску).
   - Створення ярликів на Робочому столі та в меню «Пуск».
   - Додавання в автозапуск Windows (зі згортанням у трей при вході).
   - Автоматична активація аудиту безпеки Windows (AuditPol).
   - Перевірка наявності служби IPBan.
3. Після встановлення програма реєструється у системному переліку програм Windows («Встановлені програми») із модулем коректного видалення (Uninstall.bat).

### Варіант 2: Автономний швидкий запуск (без інсталяції)
- Запустіть **IPBanControlCenter.exe** (або Run_IPBan_GUI.bat).
- IPBanControlCenter.exe є повністю автономним: якщо поруч немає файлу IPBanGUI.ps1, він автоматично використовує свій вбудований інтерфейс.
- Якщо програму запущено без прав адміністратора, Windows автоматично запропонує підвищення прав (UAC).

## Основні можливості

### 1. Керування службою Windows та Системний Трей (System Tray)
- **Індикатор стану в треї (Працює / Зупинено / Алерт)**:
  - [OK] Працює (Running): Зелений значок-щит. Повідомляє про активний захист.
  - [STOP] Не працює (Stopped): Червоний значок (якщо служба зупинена або не встановлена).
  - [ALERT] Алерт (Alert): Помаранчевий значок зі знаком оклику + спливаюче сповіщення Windows BalloonTip при появі нового блокування атакуючої IP-адреси.
- **Зручне меню в треї (ПКМ)**:
  - Відображає поточний статус і кількість заблокованих IP.
  - Швидкі дії: Запустити, Зупинити, Перезапустити, Оновити список, Відкрити вікно, Вихід з програми.
- **Фонова робота**:
  - При закритті вікна хрестиком [X] програма згортається у системний трей і продовжує відстежувати стан у фоні.
  - Подвійний клік на значок у треї повертає вікно.
- **Сучасні згладжені кнопки (Rounded Buttons)**:
  - Усі кнопки керування мають плавні заокруглені кути для комфортного вигляду.
- **Швидкий перехід**: Кнопки «Відкрити папку» та «Відкрити конфіг» у блокноті.

### 2. Вкладка «Заблоковані IP» (Firewall & Banned IPs)
- **Живий моніторинг**: Зчитування активних блокувань безпосередньо з правил брандмауера Windows (IPBan_*).
- **Швидкий пошук / фільтрація**: Фільтрація IP-адрес на льоту при введенні у поле пошуку.
- **Розблокування обраних IP**: Виділіть один або кілька IP та натисніть «Розблокувати» — утиліта відправить запит у unban.txt служби IPBan та миттєво оновить правила брандмауера.
- **Ручне блокування IP**: Можливість заблокувати підозрілий IP або підмережу негайно.
- **Очищення всіх блокувань**: Скидання всіх активних блокувань в один клік (із підтвердженням).
- **Експорт**: Збереження списку заблокованих IP-адрес у файл .txt або .csv.
- **Контекстне меню (ПКМ)**: Копіювання IP, розблокування, швидке додавання у Whitelist або перевірка геолокації та Whois на ipinfo.io.

### 3. Вкладка «Налаштування» (Config Editor)
- **Зручне редагування ipban.config**:
  - FailedLoginAttemptsBeforeBan: Поріг невдалих спроб входу перед баном (за замовчуванням 5).
  - BanTime: Час блокування (готові пресети: 1 доба, 3 доби, 1 тиждень, 30 днів, 1 година, або Назавжди 00:00:00:00).
  - ExpireTime: Термін життя невдалих спроб до скидання лічильника.
  - CycleTime: Інтервал опитування та перевірок (за замовчуванням 15 сек).
- **Опції поведінки (перемикачі)**:
  - ClearBannedIPAddressesOnRestart: Очищати всі заблоковані IP при рестарті служби.
  - ClearFailedLoginsOnSuccessfulLogin: Скидати лічильник спроб після успішної авторизації.
  - ProcessInternalIPAddresses: Обробляти та блокувати внутрішні локальні IP.
  - ResetFailedLoginCountForUnbannedIPAddresses: Скидати лічильник після розблокування.
- **Безпека**: Автоматичне створення резервної копії ipban.config.bak перед кожним збереженням та можливість відновити з бекапу.

### 4. Вкладка «Білий / Чорний списки» (Whitelist & Blacklist)
- **Білий список (Whitelist)**: Список IP/CIDR (наприклад 192.168.1.0/24, 10.0.0.1), які IPBan ніколи не заблокує.
- **Захист від самоблокування**:
  - Кнопка «+ Додати мою локальну IP» (автоматично визначає IP мережевих карт комп'ютера).
  - Кнопка «+ Додати мою зовнішню WAN IP» (визначає публічну адресу через api.ipify.org).
- **Чорний список (Blacklist)**: Перманентне блокування небажаних адрес або ботнетів.

### 5. Вкладка «Журнал та аудит» (Logs & Attack Events)
- **Перегляд логів IPBan (logfile.txt)**: Останні 250 рядків у реальному часі, моноширинний вигляд, автооновлення кожні 5 сек, кнопка очищення логу.
- **Аудит безпеки Windows (Event ID 4625)**:
  - Моніторинг останніх невдалих спроб входу в систему (RDP, Network, SMB).
  - Таблиця: Час, Користувач (User), IP-адреса джерела, Тип входу (RDP / Network / Interactive), Робоча станція.
  - Контекстне меню: можливість прямо з події заблокувати IP або додати його у білий список.

### 6. Вкладка «Інсталяція та Сервіс» (Setup & Deployment)
- **Перевірка стану**: Чи увімкнений аудит безпеки в системі, стан служби Windows, наявність архіву дистрибутива.
- **Увімкнути аудит безпеки Windows (AuditPol)**: Вмикає політику аудиту невдалих та успішних спроб входу (Logon/Logoff та Account Logon), без чого Windows не фіксує спроби підбору паролів.
- **Встановити IPBan з локального архіву**: Пошук ZIP-архіву інсталятора або вибір через кнопку «Обрати ZIP-архів...» з будь-якого диска чи мережевої папки (без прив'язки до диска D:\).
- **Встановити/Оновити з GitHub**: Запуск офіційного автоматичного скрипту встановлення свіжої версії безпосередньо з репозиторію DigitalRuby/IPBan.
- **Видалити службу**: Чисте видалення служби Windows.

## Системні вимоги
- **ОС**: Windows 10, Windows 11, Windows Server 2016 / 2019 / 2022 / 2025 (x64)
- **PowerShell**: 5.1 або новіший (входить до складу Windows за замовчуванням)
- **Права**: Права локального Адміністратора (для керування службами Windows та правилами Windows Firewall)
