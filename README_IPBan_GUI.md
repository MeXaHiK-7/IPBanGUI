# IPBan Manager & Control Center (GUI)

Повнофункціональний графічний інтерфейс та центр керування системою захисту DigitalRuby IPBan для Windows (Windows 10, Windows 11, Windows Server 2012 R2 / 2016 / 2019 / 2022 / 2025).

---

## Завантаження та релізи

Готові скомпільовані автономні `.exe` файли доступні на сторінці [**GitHub Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest):
* **`Setup_IPBanGUI.exe`** — Графічний майстер встановлення (автоналаштування ярликів, автозапуску та аудиту безпеки).
* **`IPBanControlCenter.exe`** — Портативний автономний запуск (без необхідності встановлення).

---

## Встановлення та запуск

### Варіант 1: Майстер автономної інсталяції (Рекомендовано)
1. Завантажте та запустіть **`Setup_IPBanGUI.exe`** з розділу [**Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest).
   - Файл `Setup_IPBanGUI.exe` є **повністю автономним (Single-File)**: всі скрипти, бібліотеки та іконки вбудовані всередину файлу.
   - Не вимагає наявності Git чи сторонніх компонентів.
2. Пройдіть кроки майстра:
   - Вибір шляху встановлення (за замовчуванням `C:\Program Files\IPBan Manager`).
   - Створення ярликів на Робочому столі та в меню «Пуск».
   - Додавання в автозапуск Windows (згорнуто у трей).
   - Автоматична активація аудиту безпеки Windows (`AuditPol`).
   - Перевірка та запуск служби IPBan.
3. Програма реєструється у системному списку «Встановлені програми» Windows із коректним деінсталятором, що завершує трей і зупиняє службу при видаленні.

### Варіант 2: Автономний швидкий запуск (Без інсталяції)
- Завантажте та запустіть **`IPBanControlCenter.exe`** з розділу [**Releases**](https://github.com/MeXaHiK-7/IPBanGUI/releases/latest).
- Автоматично запитує права адміністратора (UAC) при старті та працює як портативний застосунок.

## Основні можливості

### 1. Керування службою Windows та системний трей (System Tray)
- **Індикація стану служби кольоровим щитом**:
  - 🟢 **Працює (Running)**: зелений щит-іконка. Сервер під надійним захистом.
  - 🔴 **Зупинено (Stopped)**: червоний щит (якщо служба зупинена або не встановлена).
  - 🟠 **Тривога (Alert)**: помаранчевий щит зі знаком оклику + спливаюче сповіщення Windows BalloonTip при новому блокуванні атакуючих IP.
- **Контекстне меню у треї**: швидкий перегляд кількості заблокованих IP, керування службою (старт, стоп, рестарт), відкриття вікна або вихід.
- **Фонова робота**: при натисканні на хрестик `[X]` вікно згортається в трей, залишаючи службу під активним наглядом.

### 2. 🌍 Визначення країн зловмисників (GeoIP) та прапори
- **Асинхронний GeoIP резолвер**: автоматично визначає країну походження атакуючого IP без затримок та зависань інтерфейсу.
- **Локальний дисковий кеш (`geoip_cache.json`)**: мінімізує зовнішні мережеві запити, швидко завантажуючи вже відомі країни.
- **Emoji-прапори та коди**: відображення прапора та назви країни (наприклад, `🇺🇸 US - United States`, `🇩🇪 DE - Germany`, `🇺🇦 UA - Ukraine`).
- **Автовизначення локальної мережі**: приватні та внутрішні діапазони (`192.168.*`, `10.*`, `172.16-31.*`, loopback) маркуються як `🏠 LAN - Local Network`.

### 3. 📊 Аналітика та статистика атак (Вкладка «Статистика»)
- **4 оперативні KPI картки**:
  - Всього заблоковано IP-адрес.
  - Кількість унікальних країн-джерел атак.
  - Головна країна атак з відсотковою часткою.
  - Піковий часовий проміжок найбільшої активності атак.
- **Рейтинг країн за кількістю атак (Ліва панель)**:
  - Таблиця топ-країн з прапорами, кількістю заблокованих IP, відсотком від загального обсягу та візуальними псевдографічними гістограмами (`████░░░░`).
- **Розподіл атак за 24 годинами доби (Права панель)**:
  - Погодинний графік активності (00:00 – 23:00), побудований на основі точного часу блокувань IPBan та журналу невдалих входів Windows Security (Event ID 4625).
  - Автоматичне виділення пікової години червоним кольором та інформаційним банером попередження.
  - Кнопка швидкого примусового оновлення аналітики.

### 4. 🚫 Вкладка «Заблоковані IP» (Firewall Rules)
- **Точний час подій**: відображення дати і часу блокування, а також розрахованого часу автоматичного розблокування (або статусу «Назавжди»).
- **Кольорове розділення списків**:
  - Блідо-червоне підсвічування для заблокованих адрес чорного списку.
  - Блідо-зелене підсвічування для дозволених адрес білого списку.
- **Whois в один клік**: кожна IP-адреса оформлена клікабельним посиланням, що миттєво відкриває детальну картку перевірки на ipinfo.io.
- **Швидкий пошук та фільтри**: миттєва фільтрація (тільки заблоковані / тільки білий список / всі правила).
- **Керування блокуваннями**: розблокування виділених IP (через штатний механізм `unban.txt`), ручне блокування підозрілих підмереж, повне очищення списку.
- **Експорт**: вивантаження повного списку в `.txt` або `.csv` з країнами та часовими мітками.

### 5. ⚙️ Вкладка «Налаштування» (Config Editor)
- Зручне візуальне редагування параметрів файлу `ipban.config`:
  - Кількість спроб входу до блокування (`FailedLoginAttemptsBeforeBan`).
  - Тривалість блокування (`BanTime`) зі зручними пресетами (1 день, 3 дні, 1 тиждень, 30 днів, назавжди) та довільним форматом.
  - Час скидання лічильника спроб (`ExpireTime`).
  - Інтервал циклу опитування (`CycleTime`).
  - Поведінка при рестарті та успішному вході.
- Автоматичне створення резервної копії `ipban.config.bak` перед збереженням із можливістю відкату в один клік.

### 6. 📋 Вкладка «Білий / Чорний списки» (Whitelist & Blacklist)
- Керування довіреними та постійно забороненими підмережами.
- **Захист від випадкового самоблокування**: спеціальні кнопки для автоматичного визначення та додавання локального IP мережевого адаптера (`+ Додати локальний IP`) та зовнішньої статичної адреси (`+ Додати публічний WAN IP`).

### 7. 📑 Вкладка «Журнал та аудит» (Event Log & Audit)
- **Аудит спроб входу Windows (Event ID 4625)**: перегляд атак на RDP, SMB та інтерактивний вхід у реальному часі із зазначенням облікового запису, типу входу та IP-адреси нападника. Можливість заблокувати атакуючого безпосередньо з рядка журналу.
- **Журнал IPBan (`logfile.txt`)**: вбудований переглядач із можливістю автооновлення кожні 5 секунд та швидкого очищення.

### 8. 🚀 Вкладка «Інсталяція та Сервіс»
- Перевірка та одноклавішне ввімкнення політик аудиту безпеки Windows (`AuditPol`).
- Встановлення служби IPBan безпосередньо з інтернету (офіційний реліз GitHub) або з локального архіву.
- Коректне видалення служби.

### 9. 🌐 Двомовний інтерфейс (Українська / English)
- Повна підтримка української та англійської мов.
- Перемикання в один клік кнопкою **`🌐 UA`** / **`🌐 EN`** у верхній панелі.
- Автоматичне запам'ятовування вибору в реєстрі Windows (`HKCU:\SOFTWARE\IPBanControlCenter\Language`).

## Збирання з вихідного коду

Для компіляції автономних `.exe` файлів за допомогою штатного компілятора .NET Framework:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build_Binaries.ps1
```

Результатом складання є:
1. `app.ico` — багатошарова векторно-растрова іконка щита.
2. `IPBanControlCenter.exe` — автономний запускний файл (розмір ~94 КБ).
3. `Setup_IPBanGUI.exe` — графічний майстер встановлення (розмір ~250 КБ).
